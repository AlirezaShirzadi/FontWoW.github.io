# FontWoW

ابزار وب متن‌آرایی، مخصوص موبایل — متن بنویس، فونت و استایل انتخاب کن، و خروجی عکس بگیر یا کپی کن.
اجرا: **https://fontwow.github.io**

## امکانات

- ده‌ها فونت در چند دسته زبانی (فارسی، عربی، انگلیسی، ژاپنی، کره‌ای، چینی، روسی، هندی و...) + آپلود فونت دلخواه (ttf/otf/woff/woff2)
- بولد، ایتالیک، زیرخط، سایه، دورخط (با ضخامت قابل تنظیم)، شفافیت متن
- استایل‌های جعبه‌ی متن: ساده، جعبه‌ی رنگی، زیرخط ضخیم، قاب، شیشه‌ای
- اندازه، فاصله‌ی حروف، فاصله‌ی خطوط، چیدمان، حاشیه
- رنگ متن دلخواه + پس‌زمینه (رنگ ساده، گرادیان، قالب‌های آماده به تفکیک دسته، یا آپلود عکس خودت)
- خروجی PNG، کپی عکس در کلیپ‌بورد، کپی متن
- ذخیره‌ی طرح‌ها در گالری داخل برنامه (localStorage)
- تنظیمات: رنگ تم برنامه، زبان (فارسی/English)
- کاملاً سمت کاربر (client-side)، بدون سرور، بدون ردیابی

## توسعه

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

خروجی در پوشه‌ی `dist` ساخته می‌شود و با گیت‌هاب اکشن به‌صورت خودکار روی GitHub Pages منتشر می‌شود.
